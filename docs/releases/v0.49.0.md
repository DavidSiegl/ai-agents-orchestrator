## The engine is Rust now

This release replaces the Python engine, `orchestrator.py`, with the Rust one (`engine/`). The commands, flags,
prompts, files and pull requests are the same; the parity scenarios (`tests/parity`) replay the Python engine's
recordings against the new binary on every build. The binary is about half the size of the PyInstaller one, and
starts without unpacking Python.

**The tk GUI is gone.** `orchestrator gui` is no longer a command. The desktop app (`octoflow-desktop-*`) is the
window onto your runs, and `orchestrator list`, `show` and `serve` are there on the command line.

**Runs carry over.** A run that an earlier release started, running or stopped, resumes under this one with
`orchestrator resume <run>`: the state files are the same, and the Rust engine reads what the Python one wrote.

**Rolling back.** Install the previous release's binary or desktop app from its release page in place of this one,
and resume as above: a run this release started resumes under the previous one too. The previous release's
`octoflow.pyz` runs on any machine with Python 3.13 or later; this release has no `.pyz`, since there is no Python
engine left to pack.
